# Screenshots

This folder holds the screenshots referenced by the project `README.md` (English)
and `README.zh-CN.md` (Chinese). Drop your own captures in here using the exact
filenames below and the README image links will resolve automatically.

| File | What it should show | Suggested how-to |
| --- | --- | --- |
| `status-bar.png` | The balance / quota status bar rendered in the DSH Web chat composer (below the message input). | Open a conversation in `dsh web`, configure at least one provider, and screenshot the composer strip. |
| `provider-menu.png` | The provider-switch dropdown that opens when you click the provider name in the status bar. | Click the provider name in the status bar so the menu is open, then screenshot. |
| `settings.png` | The plugin settings section (**Settings → Plugins → 余额查询 / Balance**) listing providers, live dots, and the status-bar toggle. | Open the plugin settings card, expand one provider if useful, then screenshot. |

## Recommendations

- Capture at a normal window size (≥ 1200 px wide) so the bar and menu read clearly.
- Prefer a light or dark theme that matches your README screenshots consistently
  (the plugin follows the DSH theme via `theme: system`).
- Keep files reasonably sized (PNG or WebP, aim < 500 KB) so the README stays light.
